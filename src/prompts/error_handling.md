# Обработка ошибок TM4J MCP Server

## Коды ошибок и стратегии

| Код | Описание | Действие |
|---|---|---|
| `TM4J_API_ERROR` | Ошибка от TM4J API | Проверь HTTP-статус и тело ответа |
| `AUTH_ERROR` | Проблема авторизации | Перезапусти MCP-сервер с новыми credentials |
| `VALIDATION_ERROR` | Неверные входные данные | Исправь параметры и повтори запрос |
| `JIRA_RESOLUTION_ERROR` | Не удалось разрешить владельца | Проверь identifier, используй прямой account_id |

## HTTP-статусы

| HTTP Status | Значение | Поведение сервера |
|---|---|---|
| 400 | Bad Request | Валидация входных данных |
| 401 | Unauthorized | Ошибка авторизации |
| 403 | Forbidden | Не хватает прав |
| 404 | Not Found | Сущность не найдена |
| 409 | Conflict | Конфликт данных |
| 429 | Rate Limit | Автоматический retry с backoff |
| 5xx | Server Error | Автоматический retry с backoff |

## Автоматические повторные попытки

Сервер автоматически повторяет запросы при:
- HTTP 429 (Rate Limit) — экспоненциальная задержка
- HTTP 5xx (Server Error) — до 3 попыток
- Сетевые ошибки подключения

## Статусы выполнения шагов

Поле `step_status` в ответе показывает прогресс составной операции:

```json
{
  "step_status": {
    "operation_id": "op_abc123",
    "tool_name": "get_test_case_full_details",
    "overall_status": "completed",
    "steps": [
      {"step_id": 1, "description": "Загрузка тест-кейса", "status": "completed"},
      {"step_id": 2, "description": "Загрузка последнего результата", "status": "failed", "error": "Not Found"}
    ]
  }
}
```

Статусы шагов:
- `pending` — шаг ожидает выполнения
- `in_progress` — шаг выполняется
- `completed` — шаг завершён успешно
- `failed` — шаг завершён с ошибкой

## Стратегии восстановления

1. **Не найдена сущность (404)**: Используй `search_test_cases` для поиска корректного ключа
2. **Ошибка авторизации (401)**: Проверь переменные окружения TM4J_AUTH_TYPE и токен
3. **Rate Limit (429)**: Подожди — сервер делает автоматический retry
4. **Ошибка разрешения владельца**: Используй `resolve_owner` для проверки identifier
5. **Частичный отказ в составной операции**: Проверь `step_status` — некоторые шаги могли выполниться
